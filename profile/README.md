# 🌱 Twig

**Twig helps parents and kids get to know each other, strengthen their bond, and preserve the memories that matter.**

Twig is a mobile app built around small, regular moments together:

- **Daily check-ins.** A quick question each day that starts a real conversation.
- **Weekly activities.** Simple things to do together, picked for your family.
- **Memories archive.** A shared place to keep the moments you don't want to lose.
